# Архив источников стратегии фондов

Неизменные исследовательские копии материалов из официального репозитория `jackson-video-resources/markov-hedge-fund-method`, ревизия `fe24cf9426874eeabdb1bcaca2fe9d7666fb0d7c` от 20 мая 2026 года. Получены 8 октября 2026 года.

- `markov-hedge-fund-method.pine.txt` — исходный индикатор Pine v5: логарифмическая доходность за 20 баров по умолчанию, пороги ±5%, матрица соседних переходов и приближение долгосрочных долей. Архив содержит оригинальные ошибки; исправления не внесены. Для просмотра открыть как текст; для ручной проверки скопировать текст в Pine Editor TradingView. Это архив, а не наш исполняемый скрипт.
- `markov_regime.py.txt` — оригинальный самостоятельный Python-модуль: простая доходность, матрица переходов, сигнал Bull−Bear, walk-forward и отдельная сводка HMM. Сохранён для сопоставления; не запускался.
- `installation_prompt.txt` — запрос установки первой версии. Содержит ещё одну реализацию Python, которая отличается от самостоятельного модуля. Инструкции установки не выполнялись.
- `LICENSE.txt` — оригинальная лицензия MIT.

Описание параметров, ошибок, хеши и источники: документ `Стратегия_фондов_по_Pine_Script.md` в папке документов проекта.

Архивный код не является новой или исправленной торговой системой. Точный Pine Markov 2.0 в этом архиве отсутствует.
