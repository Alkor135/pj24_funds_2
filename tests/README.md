# Проверки дневных вероятностей

`test_regime_ranges.py` проверяет диапазоны с границами через 5%, полный
совместный перебор, комиссию, пропуски и конфликты, непрерывный P&L,
просадку от начального нуля и статистику по годам. Прямой независимый
перебор сверяет максимальный доход. CLI создаёт автономный HTML на
искусственных XLSX/SQLite, отдельно для MIX и RTS, без изменения входов.
Проверяет запрет перезаписи фактической SQLite из метаданных книги отчётом,
даже если БД имеет расширение `.html`.
Геометрия годовых SVG-столбцов сверяется с ручными значениями PnL:
отдельный результат каждого года и направления, отрицательные и нулевые годы.
Параметров самого тестового скрипта нет. Временные файлы находятся в `tests`.

```powershell
python -m unittest discover -s tests -p test_regime_ranges.py -v
```

`test_real_regime_trades.py` проверяет сделки по порогам Бычий/Медвежий:
целые и дробные пороги включаются, результат продажи равен −Real, комиссия в б.п. на круг
вычисляется от OPEN. Проверяются отдельные и общие результаты, нулевые
и отсутствующие Real, конфликты, параметры, чтение OPEN из исходной БД
и согласованность Real с ценами. Искусственные XLSX/SQLite создаются внутри
`tests`, автоматически удаляются; проверяется сохранность входов при CLI.
Параметров тестового скрипта нет.

```powershell
python -m unittest discover -s tests -p test_real_regime_trades.py -v
```

`test_real_regime_groups.py` проверяет новый скрипт для колонок Бычий/Медвежий:
выбор вероятностей, границы групп, порядок колонок, количества, суммы Real
и сложение двух сумм в колонке «разница». Ожидания рассчитаны вручную,
включая пропуски и нули. Проверяет выбранный лист XLSX, запуск из другой
папки и сохранность исходной книги. Параметров тестового скрипта нет;
временные файлы создаются внутри `tests` и автоматически удаляются.

```powershell
python -m unittest discover -s tests -p test_real_regime_groups.py -v
```

`test_real_groups.py` проверяет количества положительных и отрицательных Real
и их суммы по десяти фиксированным интервалам Рост/Падение, порядок колонок
и колонку «разница»: сумма положительных Real плюс сумма отрицательных Real
с сохранением знаков в обоих DF. Ожидания рассчитаны вручную,
включая границы 0%, 10%, …, 100%, пропуски, нули и пустые группы.
Дополнительно проверяется отказ при некорректных значениях и запуск из другой
папки на выбранном листе искусственной книги без изменения её содержимого.
Параметров тестового скрипта нет; временные файлы создаются внутри `tests`.

```powershell
python -m unittest discover -s tests -p test_real_groups.py -v
```

Проверки расчётов импортируют общие модули через пакет `source`; запускаемые
скрипты остаются в корне проекта. Команды запуска существующих проверок сохранены.

`test_entrypoints.py` запускает три корневых скрипта отдельными процессами
из другой рабочей папки и проверяет `--help`, создание обеих прогнозных XLSX,
стандартные входы исследования и его CSV/JSON/PNG/Markdown. Программные файлы
копируются во временный проект внутри `tests`; искусственные БД и книги
не затрагивают рабочие данные. Параметров самого тестового скрипта нет;
выбор проверок выполняется стандартными параметрами `unittest`.

```powershell
python -m unittest discover -s tests -p test_entrypoints.py -v
```

`test_real_research.py` проверяет исследование Real: строгий ввод XLSX,
разделение признаков и фактов, общий календарь, расходы 3 б.п. на круг,
причинность отбора правил и итоговые артефакты. Искусственные книги и
временные файлы размещаются внутри `tests`.
Дополнительно проверяются согласованность матриц, полнота нестандартных окон,
независимость режимных фильтров сторон, единицы смешанных таблиц и невозможность
статистического вывода по единственному блочному повтору.

```powershell
python -m unittest discover -s tests -p test_real_research.py -v
```

`verify_real_research.py` независимо читает исходные книги и готовый JSON,
проверяет SHA-256, календарь, каждый сигнал, списание расходов, итоговые метрики,
Brier/LogLoss/точность и сохранение строк CSV. Производственные модули не импортирует,
файлы не меняет. Параметр `--summary` меняет путь к JSON.

```powershell
.\.venv\Scripts\python.exe tests/verify_real_research.py
python tests/verify_real_research.py --summary outputs/real_research/summary.json
```

`test_funds_model.py` проверяет формулы методики, отсутствие будущих данных,
переименование SECID, выбор экспирации, пропуски, перенесённые цены,
резервные вероятности и структуру XLSX. Искусственная история и временные БД
позволяют проверять граничные случаи без изменения рабочих котировок.
Дополнительно проверяются фильтры командной строки, сохранение предшествующего
обучения, будущая дата и отказ при устаревшей БД. Колонка `Real` проверяется
как `CLOSE − OPEN` в пунктах: рост, падение, ноль, первый бар без обученной
модели и отсутствие факта для будущей даты или синтетических цен.

Запуск из `C:/Users/Alkor/VSCode/pj24_funds_2`:

```powershell
python -m unittest discover -s tests -v
```

Для проверок XLSX требуется `openpyxl` из корневого `requirements.txt`.
Временные файлы создаются внутри `tests` и автоматически удаляются после проверок.

`verify_real_outputs.py` независимо читает обе рабочие БД и готовые XLSX,
сверяет все даты, идентификаторы, десять колонок, суммы троек, Real в пунктах
для каждого бара и формулы последней строки.
У него два необязательных параметра: `--project` (папка проекта) и `--db-dir`
(папка БД; по умолчанию `C:/data_quote/day2`). Перед ним нужно создать обе таблицы.

```powershell
python tests/verify_real_outputs.py
python tests/verify_real_outputs.py --project C:/Users/Alkor/VSCode/pj24_funds_2 --db-dir C:/data_quote/day2
```
